# 可靠性边界与敏感性检查

## 低残差不代表外参唯一

静态场景中，大面积地面、同向墙面和稀疏远处回波可能约束部分方向，却无法可靠地区分平面内平移或某些小角度差异。不同初值/体素下出现厘米级位姿变化而验证残差近似不变时，保留候选差异和弱雷达标记，不平均这些解来宣称问题已解决。

先比较固定验证集上的逐对双向覆盖率、对应数、median/P90/P95/RMS和最差雷达。评估量程、体素、距离和法向阈值保持一致；不能只列较低的中位数或通过减少共视区域掩盖坏解。

## 最小复核

- 旧标定只作为初值：核对 frame_id 和变换方向，再用新帧验证安装是否仍合理；不要复制旧结果当作新标定。
- 对同一训练集进行有界初值扰动，固定参考雷达，记录实际扰动与种子。位姿更新应区分绕参考原点旋转和绕各雷达原点旋转的影响。
- 对不同训练单帧分别复算，比较平移和旋转；静态重复扫描并不等于新的场景独立性。
- 改变体素时记录每路候选间的变化。初始化敏感性、体素敏感性和单帧重复性分别报告，不把其中最小的一项当作整体精度。
- `converged=false` 原样保留。达到迭代上限、末步很小、信息矩阵可解都不自动等于通过验收。
- 只在完成验证集选型并冻结外参/参数后评估 test。若测试后调参，必须重新划定独立测试数据，不能继续声称原 test 未参与选型。

## 有限制的交付

可以交付标记明确的估计、已验证子图和候选，支持用户进一步检查；不得将无法区分的解标成唯一或可直接部署。所有 JSON、网页和报告保留 `status`、`warnings` 及按雷达区分的诊断。

观察到的候选跨度不是统计置信区间或物理误差上界。需要更高置信度时，增加弱雷达与邻居共同可见、法向和空间分布更丰富的靶标/实体面，或加入可信的安装测量；仅增加同一静态场景的帧数未必能解除歧义。

坐标换基和 TF/网页一致性检查只证明表达一致，不能消除原标定的不确定性。自动化不得把生成配置视为启动机器人节点或部署的授权。
